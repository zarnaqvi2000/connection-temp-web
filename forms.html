About account deletion

Google Play requires account-creating apps to provide an in-app path to account deletion and a web resource where users can request deletion. This page is designed to be that publicly accessible web resource.

The account-deletion request form should not ask users for their password. Use information such as the registered mobile number and other details needed to verify the request.
